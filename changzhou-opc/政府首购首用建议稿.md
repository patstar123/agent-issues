# 政府首购首用建议稿

> 本文是单独起草的增补建议，不替代原十条整理稿。  
> 原文第（八）条只写工业企业开放场景并购买 OPC 成果后给补贴，没有政府侧订单，也没有针对 OPC 简化采购、付款、验收。

---

## 一、提议说明

**提议人意见：** 建立 **政府首购首用** 机制。区属国企、事业单位和政务场景向 OPC 开放采购，并明确一定比例的采购份额，用政府订单的示范效应 **替代部分补贴**。同时针对 OPC 体量小、垫资能力弱，**简化采购、付款、验收流程**，避免“能进目录、拿不到钱、验收拖半年”。

一人公司最缺的不是再多一张补贴申报表，而是第一张能拿去对市场讲的订单。政府、国企、事业单位先用起来，比单纯提高补贴比例更有用，也能减轻财政直补压力。

---

## 二、建议写入讨论稿的条文

建议接在第（八）条之后单列，或并入第（八）条作第二款。场景开放对工业企业，首购首用对政府侧，不宜混成一句。

**支持政府首购首用。** 推动区属国有企业、事业单位和政务应用场景向 OPC 开放采购，对列入首购首用范围的人工智能产品和服务，明确一定比例的采购份额。以政府订单形成示范和应用案例，减少对纯财政补贴的依赖。针对 OPC 项目金额小、交付周期短的特点，简化采购、付款和验收流程，合理缩短账期，允许符合条件的项目实行预付款或分阶段付款。

---

## 三、谁买、买什么、占多少

### 1. 采购主体

- 区属国有企业（含园区开发、城建、交通、能源、文旅等）
- 区属事业单位
- 政务场景：机关信息化、一网通办、城市运行、宣传、档案、公共数据等（须符合政务安全和等保要求）

**备注：** 社会工业企业采购仍走第（八）条，不占本条“采购份额”。本条只约束政府侧和区属国企、事业单位。

### 2. 采购内容（与已有赛道对齐）

| 方向 | 可首购首用的例子 |
| --- | --- |
| 智造与四新两智 | 质检、运维助手、文档和知识库、工业智能体试点 |
| AIGC | 政务和企业宣传、招商材料、公益广告策划（不做娱乐短视频） |
| 出海 | 区属国企海外项目的多语种内容和站点（与第（十）条费用补贴从高不重复） |
| AI 安全 | 脱敏、模型网关、内容识别、私有化部署（政务和国企优先） |
| 其他 | 办事助手、培训内容、档案和知识检索等小额创新应用 |

须是 OPC 自研或为主交付的产品、服务，不能只是转包大集成商的劳务。

### 3. 采购份额（讨论数，原文没有）

建议在细则里写清，正文只保留“一定比例”也可以。

- 区属国企、事业单位年度信息化、数字化、宣传文化类采购中，面向 OPC 或“首购首用目录”内产品的金额，原则上 **不低于该类采购的 5%—10%**；
- 或：单列年度 OPC 首购首用意向订单，由管委会汇总发布，国企和事业单位认领；
- 未完成份额的，下一年度说明原因，不搞一刀切处罚，但纳入国企考核加分项。

份额要合法：走政府采购中小企业预留、创新产品首购首用目录、框架协议、公开征集等现有通道，**不写“直接指定、规避招标”**。

---

## 四、针对 OPC 简化采购、付款、验收

这是本条能否落地的关键。份额写了、流程不改，一人公司仍做不了政府的生意。

| 环节 | 现在常见情况 | 针对 OPC 的建议 |
| --- | --- | --- |
| **采购** | 门槛高、标书重、要业绩和注册资本 | 建立 OPC / 创新产品首购首用目录；小额项目走框架协议、征集入围、快速比选；不把“三年同类业绩、高注册资本”当前置 |
| **合同** | 条款按大集成商来 | 提供简易合同范本；允许按模块、按阶段交付；知识产权约定清楚，不搞无底线的成果上交 |
| **付款** | 验收后长时间账期，OPC 垫不起 | 符合条件的可 **预付 20%—30%**；其余按节点付；验收合格后建议 **30 日内结清**，原则上不超过 60 日 |
| **验收** | 按大型信息化项目组织，周期长 | 小额、标准产品实行一次性或两阶段验收；政务项目安全审查不减，但商务验收与安全审查并行，不串成超长链路 |
| **担保** | 要履约保函、质保金比例高 | 小额项目降低或免收履约保函；质保金比例从低，或用保函替代长期扣款 |

**建议写进细则的三句硬话：**

1. 目录内、单项金额较低的项目（例如不超过 50 万元，具体数区里定），适用简易采购和快速验收。
2. 不得以注册资本、从业人员数量、是否有政府业绩为由，把 OPC 挡在门外。
3. 逾期未付的，按合同支付违约金或内部通报，防止“首购”变成“首欠”。

---

## 五、怎样用订单替代部分补贴

原则：能形成政府或国企订单的，少发或不发同类运营补贴；订单拿不到的早期项目，仍可用算力券、空间、基金。

| 情形 | 建议 |
| --- | --- |
| 已获本条项下政府 / 国企订单 | 同一内容不再领第（八）条场景资助、第（九）条内容补贴；算力券、免租可以保留 |
| 订单金额已覆盖研发和交付 | 不再叠加上限内的全额补贴 |
| 仅入选目录、尚未成交 | 不算“已获订单”，空间和算力支持仍可给 |
| 四新两智相关首购 | 份额和简化流程上优先，与倾斜原则一致 |

这样财政从“补申报”转向“下订单”，也方便考核：看成交笔数、金额、是否按期付款，而不是只看发了多少补贴。

## 六、和已有条款的分工

| 条款 | 买的人 | 给 OPC 的是什么 |
| --- | --- | --- |
| 第（八）条 | 区内工业企业 | 场景开放 + 按成交额补贴 |
| **本条** | 区属国企、事业单位、政务场景 | **订单和份额** + 简化流程；用订单替代部分补贴 |
| 第（九）条 | 企业委托宣传 / 出海 / 广告 | 按合同补贴；政府宣传类优先走本条采购 |
| 第（三）条 | — | 算力券，与订单不冲突 |
| 第（五）条 | — | 股权投资，不替代采购付款 |

## 七、还需要拍板的事项

1. 本条单列还是并入第（八）条。建议单列，买方不是一类人。
2. 份额写 5%—10%，还是只写“一定比例”，数字放考核文件。
3. 预付款比例、结清时限（30 日 / 60 日）和简易采购金额线。
4. 首购首用目录由谁维护（财政、政务、科技或管委会），多长时间更新一次。
5. 与《政府采购法》及省、市创新产品首购首用已有规定如何衔接，印发前须和财政、公管对口径。
